# КП 2.6 — TaskFlow

Продовження КП 2.5: форми створення та редагування завдань, `v-model`, валідація, Props/Emits, реактивна статистика.

## Запуск

```cmd
npm install
npm run dev
```

Перейдіть за адресою `http://localhost:5173/` → **Завдання** → **+ Додати завдання**.

## Перевірка

1. Порожня форма + «Створити завдання» → помилки назви та дати.
2. Заповнити назву, опис, статус, пріоритет і дату → попередній перегляд.
3. Створити завдання → кількість збільшується з 6 до 7.
4. «Редагувати» → зберегти; перевірити кнопку «Скасувати».
5. Головна сторінка показує оновлену статистику.
6. F5 скидає дані до 6 записів — за умовою методички.

Додатково: підрахунок символів, що залишилися, та кнопка «Очистити форму».

## Збірка

```cmd
npm run build
```

Окрема публікація: репозиторій `taskflow-kp-2-6` та Cloudflare Worker `taskflow-kp-2-6`.
