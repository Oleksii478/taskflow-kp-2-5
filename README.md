# TaskFlow — КП 2.8

Продовження TaskFlow після КП 2.6. Пошук за назвою й описом без урахування регістру, комбіновані фільтри, сортування за назвою, пріоритетом, терміном і статусом, підтвердження видалення. Збережено форму створення/редагування КП 2.6 з валідацією та попереднім переглядом. Додатково — лише невиконані, очистити пошук, відсоток виконання, сортування дат у зворотному порядку.

## Запуск
```bash
npm install
npm run dev
```

## Збірка
```bash
npm run build
```

Дані зберігаються у пам'яті сторінки. Після F5 повертаються 6 початкових завдань.
